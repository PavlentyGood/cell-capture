# фича - создание пользователя

## предусловия

- переданы айди пользователя, имя пользователя (оба обязательны к заполнению)
- данный айди еще не существует в редакторе
- имя не превышает 100 символов и не пустое
- айди имеет тип UUID

## постусловия

- в редакторе появился новый пользователь с переданными айди и именем

## ответы на вопросы

- типы пользователя: собственные в field-editor (не переиспользовать kernel).
- проверка уникальности id будет выполнена вне доменной модели.
- package домена: `io.github.pavlentygood.cellcapture.fieldeditor.domain`.
