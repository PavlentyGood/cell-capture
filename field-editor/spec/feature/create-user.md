# фича - создать пользователя

## входные данные
- айди пользователя
- имя пользователя

## выходные данные
- пусто

## инварианты
- айди типа UUID
- айди еще не существует в системе
- имя не пустое и не состоит из пробелов
- имя не превышает 100 символов

## постусловия
- в системе есть новый пользователь с переданными свойствами
