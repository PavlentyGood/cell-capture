# Правила работы над проектом для ИИ-агента

## Общие правила

- изъясняйся кратко.
- запрещено писать комментарии и javadoc в коде.
- запрещено читать содержимое каких-либо файлов. это касается и агентов Explore и Plan. передавай им явно этот запрет. запрет не действует только на примеры кода, данные в скиллах.
- запрещено исследовать структуру проекта за пределами каталога, в котором открыта текущая сессия claude code. это касается и агентов Explore и Plan. передавай им явно этот запрет.
- если агент задает вопросы, то затем при выполнении задания необходимо сохранить ответы от пользователя в спеку в раздел "ответы на вопросы" в краткой форме.
- выполнение спецификации подразделяется на 2 этапа: создание тестов (TDD), а только затем реализация спецификации.
- запуск gradle-задач через обертку gradlew.
- после написания кода проверь тестовое покрытие через gradle check и стилистику кода через gradle detekt.
- если надо прочитать скилл, то загрузки его через инструмент Skill.
- для исследования структуры проекта и чтения файлов используй в первую очередь MCP.

## Применяемые подходы

- Domain-Driven Design
- Value Objects
- Clean Architecture
- Детройтская школа тестирования
- Either (arrow.core)
- JUnit 5 + Kotest (shouldBe assertions)
- TDD
